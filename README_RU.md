# Nitro Fans — плагин управления вентиляторами для Omarchy

Плагин для **Omarchy**, добавляющий на панель управление вентиляторами ноутбука
**Acer Nitro AN515-44**: слайдер скорости, пресеты режимов, температуры и popup.

## Для какого ноутбука

Разработан и проверен на **Acer Nitro AN515-44**.
Управление происходит через `nitro-fan` (переключение режимов) и `nbfc`
(чтение текущих оборотов и температур CPU / GPU / NVIDIA).

## Что входит

| Плагин | Описание |
|--------|----------|
| `nitro.fans` | Виджет панели (bar-widget): иконка + popup со слайдером скорости, пресетами Quiet/Balanced/Performance/Turbo, режимом Auto, температурами и предупреждением о перегреве |

## Что нужно (пакеты)

Перед установкой убедитесь, что в системе есть:

| Компонент | Пакет / источник | Зачем |
|-----------|------------------|-------|
| Omarchy | omarchy | Обоолочка и панель |
| nbfc | `nbfc-linux` (AUR) | Чтение оборотов вентиляторов |
| nitro-fan | `~/.local/bin/nitro-fan` или AUR `nitro-fan` | Переключение режимов вентилятора |
| git | git | Клонирование репозитория |
| yay | yay (AUR helper) | Установка пакетов из AUR |
| curl | curl | Однострочная установка |

## Установка

### Способ 1: одна команда (рекомендуется)

```bash
bash -c "$(curl -fsSL https://github.com/rLeeKen/omarchy-acer-nitro-fan-control/raw/main/install.sh)"
```

### Способ 2: вручную

```bash
git clone https://github.com/rLeeKen/omarchy-acer-nitro-fan-control.git
cd omarchy-acer-nitro-fan-control
chmod +x install.sh
./install.sh
```

### На konci установки

Установщик спросит, куда разместить popup с вентиляторами на панели Omarchy:

1. **Слева** (`left`)
2. **Справа** (`right`) — по умолчанию
3. **По центру** (`center`)

Виджет `{"id": "nitro.fans"}` добавляется в конец выбранной секции
`bar.layout` в `~/.config/omarchy/shell.json` без замены виджетов других
плагинов.

### Применить изменения

После установки перезапустите оболочку Omarchy:

```bash
omarchy restart shell
```

## Управление

Popup открывается кликом по иконке виджета на панели.

| Клавиша | Действие |
|---------|----------|
| `←` / `→` | Переключить пресеты: Quiet → Balanced → Performance → Turbo |
| `↓` из пресета | Перейти в режим Auto |
| `↑` из пресета | Перейти к слайдеру скорости |
| `↓` из слайдера | Перейти в Quiet |
| `↑` из слайдера | Перейти в Auto |
| `Enter` | Применить выбранный режим / значение слайдера |

Цвет иконки меняется на „тревожный“, если температура CPU или GPU выше 85 °C.

## Удаление

```bash
rm -rf ~/.config/omarchy/plugins/nitro.fans
omarchy restart shell
```

Если нужно вернуть панель в прежнее состояние, также можно восстановить
`~/.config/omarchy/shell.json` из бэкапа, который установщик создаёт перед правкой
(`shell.json.bak.YYYYMMDD-HHMMSS`).
